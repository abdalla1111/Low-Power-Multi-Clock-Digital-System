## Time-based power

The supplied report is titled **Time Based Power**, generated by PrimeTime PX O-2018.06-SP1. The original script selects the SS library and reads activity from a GLS VCD.

| Component | Power (mW) | Fraction |
|---|---:|---:|
| Cell internal | 0.2148 | 48.61% |
| Net switching | 0.2085 | 47.17% |
| Cell leakage | 0.01864 | 4.22% |
| **Total** | **0.442** | **100%** |

The total is the report's `4.420e-04 W`, expressed as mW; the unit interpretation was confirmed by the project author. Components are independently rounded in the tool report. Clock-network power is 95.52% in the report's separate grouping; this is a different breakdown and should not be added to the component percentages above.

This is activity-dependent power for the recorded setup, not a worst-case guarantee or a measurement from fabricated silicon. Raw peak power/time are available in the original report; its excerpt does not print their units, so they are not converted here. Large activity dumps are excluded and can be regenerated using the supplied GLS bench.

## Functional and gate-level verification

The original functional bench was freshly compiled and run on **Icarus Verilog 12.0** during repository preparation: **28 passed, 0 failed**, with `ALL 28 TESTS PASSED`. See the [new functional simulation transcript](../verification/rtl/reports/iverilog.log). This run uses the behavioral functional RTL and does not replace the commercial gate-level or timing checks.

- The functional testbench contains 28 tests, using prescales 32, 16, and 8.
- The supplied post-PnR GLS run executes four scoreboard cases at prescale 32: register write, register read, ALU with new operands, and ALU with stored operands.
- The GLS transcript ends with `TOTAL=4 | PASS=4 | FAIL=0` and `ALL 4 TESTS PASSED`.
- The same transcript contains SDF annotation diagnostics and a standard-cell `$setup` timing check error. Functional scoreboard success therefore does **not** establish a timing-clean GLS run.
- The original GLS launcher used `-sdfnoerror`. The repository launcher uses SDF maximum-delay annotation without that suppression flag; a new run may expose additional annotation failures that must be investigated.

The larger prescale test sequences remain commented out in the original GLS testbench; they are not counted as executed GLS tests.

Evidence: [GLS transcript](../verification/gls/reports/transcript.log), [functional bench](../verification/rtl/system_tb.v), [GLS bench](../verification/gls/system_tb.v).
